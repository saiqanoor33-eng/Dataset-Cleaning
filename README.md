# Task 01 — Clean & Prepare a Dataset

## Project Overview

This project demonstrates how to clean and prepare a real-world movie dataset using Python and Pandas.

## Dataset

The dataset contains movie information including:

* Movie title
* Genres
* Release year
* Rating

## Data Cleaning Steps

1. Loaded the dataset using Pandas.
2. Checked for missing values.
3. Identified and removed duplicate records.
4. Converted `year` and `rating` into appropriate numeric data types.
5. Handled missing values using suitable replacement values.
6. Removed invalid year and rating values.
7. Exported the cleaned dataset as `movies_cleaned.csv`.
